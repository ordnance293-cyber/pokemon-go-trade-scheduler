# Stock Copy Fire Prefix Design

## Goal

Make the generated 「現貨文案」 match the requested visual format by prefixing every non-empty stock item line with exactly `🔥 ` (fire emoji followed by one space).

Example:

```text
🔥 26年異色起源特招帕路奇亞
🔥 26年特別背卡異色洛奇亞
🔥 26年特別背卡異色哲爾尼亞斯（現貨2隻）
```

## Scope

Only change the text generated by the 「📝 現貨文案」 action and therefore the text copied by 「複製文案」.

Do not change:

- inventory cards or displayed Pokémon names
- Firestore inventory data
- grouping rules
- year / color / back-card formatting
- stock counts
- quantity suffix behavior (`（現貨X隻）` only when quantity > 1)
- the empty-stock message `目前無現貨寶可夢。`
- scheduling, trading, completion, search, or account behavior

## Implementation

Keep the existing grouping loop and add the prefix at final line assembly:

- quantity = 1: `🔥 ${label}`
- quantity > 1: `🔥 ${label}（現貨${quantity}隻）`

The prefix must contain exactly one normal space after `🔥` so the modal matches the supplied screenshot.

## Error Handling

No new error path is introduced. Clipboard behavior continues to copy the current textarea value unchanged.

## Testing

Add or update the focused stock-copy test so it verifies:

1. every generated stock item line starts with `🔥 `
2. single-quantity rows still omit the quantity suffix
3. multi-quantity rows still include `（現貨X隻）`
4. the empty-stock message is unchanged and does not receive a fire prefix

Run the existing repository test suite after the change.

## Acceptance Criteria

The modal and copied clipboard text use the same format, with each stock line beginning with `🔥 ` and all unrelated behavior unchanged.
